# 婚礼抽奖 · 部署说明

黄继安 & 聂玮婷 · 2026.10.25

## 快速启动（本地验证 / 服务器部署 通用）

```bash
cd app
python3 server.py            # 默认 8000 端口
# 或指定端口：python3 server.py --port 8080
```

零依赖：只需要 Python 3.8+，不用 pip 装任何东西。

启动后访问：

| 页面 | 地址 | 用途 |
|---|---|---|
| 入口导航 | http://IP:8000/ | 四个入口 + 使用流程 |
| 宾客领券 | http://IP:8000/register.html | 做成二维码印桌卡 |
| 抽奖大屏 | http://IP:8000/screen.html | 连 LED/投影全屏 |
| 控制台 | http://IP:8000/admin.html | 主持人操作（密码默认 `hn2026`） |
| 奖项配置 | http://IP:8000/config.html | 奖项/婚礼信息/改密码 |

## natapp 内网穿透

把隧道指向本服务端口（如 8000）即可，宾客手机扫码直达。
建议婚礼前用真实手机扫码走一遍：领券 → 控制台看人数 → 抽一轮。

## 数据文件（都在本目录，重启不丢）

- `data.db` — SQLite 主库（宾客 / 中奖 / 配置 / 流水号）
- `data_backup.json` — 每次变更自动导出的全量备份，可直接人工查看

备份数据 = 复制这两个文件。清空重来 = 控制台「清空全部数据」按钮（推荐），
或停服后删除这两个文件再启动。

## 后台常驻（Linux 服务器）

```bash
nohup python3 server.py --port 8000 > server.log 2>&1 &
```

## 架构说明

- 检测到 server.py → 自动进入**服务器模式**：所有设备数据集中，大屏跨设备实时联动（SSE 推送）
- 直接双击 html / 纯静态托管 → 自动回落**本地模式**：数据存在浏览器本地，大屏与控制台需同一浏览器开两个标签页（可用于静态预览和动画 demo）
- 大屏动画预览（无需任何数据）：`screen.html?demo=1`
